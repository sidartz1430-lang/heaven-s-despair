# Workspace instructions

This repository is the GitHub home for work in this workspace, as requested by the user.

- Remote: https://github.com/sidartz1430-lang/heaven-s-despair
- Save meaningful completed progress with descriptive commits and push it to this repository after each work session, unless the user asks otherwise.
- Preserve existing work. Fetch remote changes before publishing and never force-push or overwrite unrelated changes.
- Keep credentials, secrets, local configuration, dependencies, and scratch files out of commits. Use work/ for temporary files and outputs/ for user-facing deliverables.
- Check the relevant changes before committing. Report whether progress was successfully saved to GitHub; if a push fails, retain local work and explain the blocker.
- If shell Git authentication is unavailable, use the connected GitHub tools to publish changes, then fetch and synchronize the local checkout.

These instructions apply to this repository and workspace. They do not automatically synchronize other chats or projects.
