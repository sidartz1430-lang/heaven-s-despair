GitHub archive: https://github.com/sidartz1430-lang/heaven-s-despair/tree/main/outputs/work-image-archive

Recovery after any later local cleanup:
Use the archivePath from the manifest, clear its skip-worktree flag if set, and restore from the archived commit:
git update-index --no-skip-worktree -- 'outputs/work-image-archive/images/EXAMPLE.png'
git restore --source=bfefe15c9757f301fe999e95ba7514bb1957d6e7 --worktree -- 'outputs/work-image-archive/images/EXAMPLE.png'
You can copy the restored file back to its originalPath in work if needed.
Git LFS must be installed to restore the large atlas files.
